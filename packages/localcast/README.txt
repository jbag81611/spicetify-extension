LocalCast — Spotify 로컬파일을 오라스튜디오5로 자동 전송
==========================================================

[하는 일]
- Spotify에서 Connect로 오라스튜디오5를 골라 듣다가 로컬파일 차례가 되면,
  자동으로 PC 재생으로 바꾸고(PC 쪽 Spotify 소리만 음소거) 그 파일을
  AirPlay 2로 스피커에 보냅니다 (연결음 없음, 볼륨은 스피커 볼륨 그대로).
- 다음 곡도 로컬파일이면 계속 AirPlay, 스포티파이 곡이면 다시 Connect로 돌아갑니다.
- 재생/일시정지/탐색/볼륨은 Spotify 앱에서 그대로 조작하면 스피커에도 반영됩니다.
- 로컬파일을 AirPlay로 재생하는 동안 아래에 하늘색 "○○ AirPlay에서 재생 중" 줄이 뜹니다.
- 볼륨은 Connect ↔ AirPlay 사이에서 그대로 이어지고, PC 스피커 볼륨과는 따로 기억됩니다.
- 기기 목록에서 "이 컴퓨터"를 직접 고르면 평소처럼 PC 스피커로 재생합니다(AirPlay 안 함).
- 스피커 연결 중에 로컬파일을 더블클릭/재생 버튼으로 틀어도 자동으로 스피커로 재생합니다.
  (오른쪽 클릭 → "스피커로 재생 (LocalCast)"도 됩니다)
- 스피커(Connect) 연결 중에도 재생목록에 로컬파일이 보이게 합니다(누르면 AirPlay로 재생).
- 오른쪽 "재생목록"(다음 재생) 패널에도 로컬파일을 원래 순서 자리에 표시합니다(앨범 사진 포함, 누르면 AirPlay로 재생).
- 스피커 연결 중 로컬파일을 "대기열에 추가"/"다음에 재생"하면 LocalCast가 기억했다가 지금 곡 다음에 AirPlay로 재생합니다.
  안 보이면 다른 페이지에 갔다가 재생목록을 다시 열어보세요.
- PC 스피커로 로컬파일을 듣다가 기기 목록(Connect)에서 스피커를 누르면
  ("이 트랙을 재생할 수 없음" 대신 "AirPlay로 재생"으로 바뀜) 그 위치부터 AirPlay로 이어서 재생합니다.

[준비물]
- Python 3.11 이상 (python.org, 설치 첫 화면에서 "Add python.exe to PATH" 체크)
- Spicetify (이미 사용 중)
- PC와 오라스튜디오5가 같은 와이파이

[설치 / 업데이트]
- LocalCast_Setup.bat 하나만 실행하면 됩니다. 지우거나 압축을 풀 필요 없습니다.
  → C:\LocalCast 에 설치하고 (기존 LocalCast 파일은 전부 지우고 새로 깖), 라이브러리 설치 + Spicetify 확장 적용 +
    방화벽 허용 + 보조 프로그램 실행 + PC 켤 때 자동 실행 등록까지 한 번에 합니다.
- 업데이트 때도 새 LocalCast_Setup.bat 을 실행만 하면 됩니다. 기존 파일(설정·로그 포함)은 전부 지워지고 새로 설치됩니다.
- 처음 한 번은 방화벽 관리자 확인 창이 뜹니다 → "예". (위치가 고정이라 그 뒤로는 안 뜸)
- 로그 파일도 이 폴더에 있습니다 (localcast.log, airplay_debug.log).

[파일 설명]
- 1_install.bat        : (설치 파일이 자동 실행) 이 폴더에서 다시 설치할 때
- 2_restart_helper.bat : config.json 을 바꾼 뒤 보조 프로그램 재시작
- 3_debug_console.bat  : 문제 확인용 (보조 프로그램을 창에 띄워 실행)
- 4_autostart_off.bat  : 자동 실행 해제 + 보조 프로그램 종료
- 5_airplay_test.bat   : 방화벽 허용 + AirPlay 10초 테스트 (볼륨 15%) — AirPlay가 안 될 때

[사용]
- Spotify 상단에 AirPlay 모양 LocalCast 버튼, 프로필 메뉴에 LocalCast 메뉴가 생깁니다.
  · LocalCast 켜기/끄기
  · LocalCast 상태 보기: 보조 프로그램/스피커/이 PC 인식 여부 확인
  · LocalCast 음악 폴더 다시 읽기: 새 파일을 추가했을 때

[설정 — config.json (메모장으로 수정 후 2_restart_helper.bat 실행)]
  * 들어 있는 config.json에는 로컬파일 폴더(OneDrive 바탕 화면\스포티파이 로컬파일)가 미리 들어 있습니다.
- speaker_name : 스피커 이름 일부 (기본 "Aura Studio 5")
- music_folders: 로컬파일 폴더. 비워두면 음악/다운로드 폴더 + Spotify 설정에서 자동 탐색
                 예) ["D:\\Music", "C:\\Users\\지훈\\Downloads"]   ← 역슬래시는 두 번
- pc_device_name: Spotify 기기 목록에 보이는 이 PC 이름 (못 찾을 때만)
- switch_lead_ms: 곡 끝나기 몇 ms 전에 로컬파일로 넘어갈지 (기본 800)
                 다음 음원이 잠깐 보였다가 돌아오면 늘리고(예: 1200), 곡 끝이 잘리면 줄이세요.
- airplay_ip   : AirPlay 스피커를 못 찾을 때만 IP 입력 (예: "172.30.1.80")
- max_speaker_volume: 오라스튜디오 최대 볼륨 % (기본 50). Connect/AirPlay 모두 이 이상 안 올라감
- airplay_latency_ms: AirPlay 버퍼 ms (기본 1500). 소리가 끊기면 2000~2500으로 올리고, 탐색 반응을 더 빠르게 하려면 1000으로

[문제 해결]
- 기록은 localcast.log 에 남습니다. 문제가 생기면 이 파일 내용을 보여주세요.
  AirPlay 자세한 기록은 airplay_debug.log 에 남습니다.
- AirPlay가 안 됨("Operation timed out"): 5_airplay_test.bat 실행 → 관리자 확인 "예".
  그래도 실패하면 스피커 전원을 껐다 켜고 다시 테스트.
- "파일을 찾지 못했어요": Spotify 로컬파일 폴더를 music_folders에 추가
- "이 PC를 찾지 못했어요": Spotify 기기 목록의 이 PC 이름을 pc_device_name에 입력
- 스피커를 못 찾음: speaker_name 확인, 또는 airplay_ip에 스피커 IP 입력
- Spotify 소리가 계속 음소거: 2_restart_helper.bat 을 실행하면 해제됩니다
  (또는 Windows 볼륨 믹서에서 Spotify 음소거 해제)

[안정성]
- 스피커 연결이 끊기면 자동으로 다시 연결해 같은 위치부터 이어서 재생합니다.
- 연결 실패가 반복되면 스피커 IP를 다시 찾습니다. 스피커가 잠깐 연결을 거부하면 몇 초간 다시 시도합니다.
- 보조 프로그램이 비정상 종료되면 자동으로 다시 켜집니다.
- 일시정지 중에도 스피커와의 전송을 끊지 않고(무음 전송) 유지해, 오래 멈췄다 다시 재생해도 소리가 안 나는 일이 없게 했습니다.
- 로컬파일 → 로컬파일로 넘어갈 때는 연결을 끊지 않고 같은 연결에서 바로 다음 곡으로 바꿉니다.
- PC 볼륨이 오라스튜디오로 넘어가지 않게: 볼륨은 지금 재생 기기를 확인한 뒤에만 바꾸고, 사용자가 볼륨바를 만지지 않았는데 스피커 볼륨이 PC 볼륨 값으로 바뀌면 바로 되돌립니다.
- 로컬파일은 스피커에서 소리가 실제로 나오는 순간에 맞춰 Spotify 재생바·가사가 움직입니다
  (새 곡 시작 때는 소리가 나올 때까지 재생바가 0:00에 잠깐 멈춰 있음).
  가사가 아직 조금 어긋나면 config.json 의 airplay_audio_delay_ms (기본 1700) 를 조절하세요. 가사가 빠르면 늘리고, 늦으면 줄임.
- 탐색을 여러 번 연속으로 해도 마지막 위치 하나만 처리하고, 소리 전송이 멈추면 그 위치에서 자동으로 다시 연결합니다.

[구성]
- bin\lc_airplay.exe : AirPlay 2 송신 프로그램 (오픈소스 airplay2-rs 기반, GPL-3.0)

[한계]
- Connect ↔ AirPlay 전환 때 2초 정도 끊김이 있습니다 (연결 시간).
- 로컬파일 재생 중 일시정지/탐색은 AirPlay 연결을 유지한 채 바로 반영합니다(스피커 버퍼만큼 약간 늦음).
- 로컬파일 직전 곡은 끝나기 약 0.8초 전에 멈추고 넘어갑니다(switch_lead_ms).
- 셔플일 때는 남은 로컬파일 비율만큼 확률적으로 끼워 넣습니다(실제 셔플과 순서는 다름).
- .wma 는 재생하지 못해 건너뜁니다.
- Spotify 내부 구조가 바뀌면 업데이트가 필요할 수 있습니다.
